### Popup and editing examples

Open the popup examples in a full browser tab and make the preview at least **1280 px wide**. The embedded preview on this documentation page may be narrower; below the breakpoint, cards navigate instead. Popup content in these examples is local demonstration data and does not require a Plone backend.

- [Visualisation card with popup enabled](https://eea.github.io/eea-storybook/?path=/story/eea-listing-block-cards--popup-enabled).
